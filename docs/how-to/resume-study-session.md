# How to Resume a Study Session

The app remembers where you left off. You can resume an interrupted session or start a fresh one at any time.

## Resume from the Home Screen

1. Open the app. Each book card shows its current state:
   - **No active session** — a single **Start** button.
   - **Active session in progress** — **Resume** + **New** buttons.
2. Tap **Resume** to continue exactly where you stopped.
3. Tap **New** to open the mode selector and begin a brand-new session.

## Resume a Specific Past Session

1. On a book card, tap the **⋯** (more) menu.
2. Choose **Records**.
3. The list shows every past attempt for that book:
   - Mode name
   - Start date and time
   - Progress (e.g., `3/10`)
   - Status: **In progress**, **Completed**, or **Abandoned**
4. Tap any record to resume it.

## How Sessions Work by Mode

| Mode | Can I have multiple active sessions? | What happens when I finish? |
|---|---|---|
| **Practice** | No — one active session per book | The session becomes inactive; next Start creates a new one |
| **Review** | No — one active session per book | The session is marked completed |
| **Preview** | No — one active session per book | The session becomes inactive |
| **Test** | Yes — each Test is its own record | The session is marked completed and stays in Records forever |

## Tips

- If you want to restart a Practice or Review from scratch, tap **New** instead of **Resume**.
- Completed sessions remain in **Records** for reference.
